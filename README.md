# Final Orginity — Tradução PT-BR

Tradução não oficial de Final Orginity para português brasileiro, com opção de alternar entre português e inglês nas opções do jogo.

## Download

[Baixar a tradução para Final Orginity v0.6.0 B (Windows)](https://github.com/NiLast/Final-Orginity-PTBR/releases/download/v0.6.0-B/Final-Orginity-v0.6.0-B-PTBR.zip)

## Instalação

1. Feche o jogo.
2. Baixe o ZIP da tradução e extraia todo o conteúdo na pasta principal do jogo, onde ficam as pastas `data` e `js`.
3. Execute `Aplicar-Traducao.bat` e aguarde a confirmação de instalação.
4. Abra o jogo e selecione **Português (Brasil)** nas opções de idioma.

Mantenha a pasta `_arquivos` junto do instalador.

## Sobre esta versão

**Versão do jogo usada como base: Final Orginity v0.6.0 B — Windows.**

O pacote traduz diálogos, escolhas, menus e textos de missões, mantendo o inglês disponível. A instalação preserva os arquivos de mapas e os saves no disco.

O download contém o patch; o jogo deve ser obtido separadamente. As licenças dos componentes de terceiros acompanham o pacote.
